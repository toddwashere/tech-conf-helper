# Git Rules

- `[GIT-01]` Conventional commits: `feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:`. Say why, not what.
- `[GIT-02]` One feature per branch and PR, so Gitar reviews each feature. PR body: `## Changes` bullets and a `## Testing` checklist of what to open, click, and verify.
- `[GIT-03]` When updating a PR description, never uncheck or overwrite checked items.
- `[GIT-04]` Commit and open PRs as part of each phase, then wait for Gitar's review before merging.
- `[GIT-05]` Keep AI attribution in commits and PRs. The hackathon rules require disclosing AI use.
